# A/B Test for SaaS Onboarding

Учебный проект по продуктовой аналитике на синтетических данных.

Проверяется новый onboarding для SaaS-сервиса: в тестовой версии пользователь проходит пошаговый сценарий подключения магазина и открытия первого аналитического отчёта.

## Результаты

В эксперименте после очистки данных осталось **2 400 пользователей** — по 1 200 в control и test.

Основная метрика — Activation Rate:

- control (A): **46,8%**;
- test (B): **57,1%**;
- абсолютный эффект: **+10,2 п.п.**;
- относительный uplift: **+21,9%**;
- p-value: **5,03e-07**;
- 95% CI для разницы: **[6,3; 14,2] п.п.**

Разница статистически значима.

Дополнительно:

- D7 retention среди активированных: статистически значимого изменения на уровне 5% не обнаружено (`p = 0,089`);
- Support Ticket Rate снизился с **17,7% до 12,6%**;
- медианное время подключения магазина снизилось примерно с **16,4 до 11,4 минуты**.

## Вывод

Тестовая версия заметно увеличила Activation Rate и не ухудшила проверенные guardrail-метрики. На этих данных я бы рекомендовал rollout новой версии с дальнейшим мониторингом D7/D30 retention.

Важно: датасет синтетический, поэтому проект показывает подход к анализу A/B-теста, а не результат реального эксперимента компании.

## Что есть в проекте

- проверка качества и очистка данных;
- проверка размера и баланса групп;
- onboarding-воронка;
- proportion z-test для основной бинарной метрики;
- абсолютный и относительный uplift;
- 95% доверительный интервал;
- анализ D7 retention;
- guardrail по обращениям в поддержку;
- сегментный анализ по устройствам;
- продуктовый вывод по результатам эксперимента.
